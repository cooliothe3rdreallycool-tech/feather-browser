# Feather

An ultra-light Chromium browser for Windows, about 1.5 MB, with a Pi-hole-style ad blocker (YouTube included), built-in AI assistants, a password locker, tab islands, and themes.

## Download

Get the latest version from **[Releases](https://github.com/cooliothe3rdreallycool-tech/feather-browser/releases/latest)**. Feather keeps itself up to date from there.

Every official update is signed with the author's private key. Feather checks that signature before it installs anything and refuses updates that aren't signed.

## Help and feedback: the Feather forums

- **Questions:** ask in the [Q&A forum](https://github.com/cooliothe3rdreallycool-tech/feather-browser/discussions/categories/q-a).
- **Ideas:** suggest features in the [Ideas forum](https://github.com/cooliothe3rdreallycool-tech/feather-browser/discussions/categories/ideas).
- **Bugs:** [report a bug](https://github.com/cooliothe3rdreallycool-tech/feather-browser/issues/new?template=bug_report.yml).
- **Broken page:** a website that doesn't work in Feather can be reported from inside Feather (menu > Help > Report a broken page). It fills in the page and your Feather version for you.

You need a free GitHub account to post. Please be kind, and don't post passwords or personal information.
